\noindent The following questions should be asked to each participant at the start of their session before they use the application.
\\\textbf{PARTICIPANT INFORMATION}
\begin{enumerate}
    \item What is your name?
    \item How old are you?
    \item What gender do you identify with? 
    \item What is your occupation?
    \item Have you ever had a knee injury? \textbf{Yes/No}
    \begin{enumerate}
        \item If \textbf{YES}, was it in the past 5 years?
        \item If \textbf{YES}, have you had physiotherapy after your knee surgery?
        \item If \textbf{NO}, have you had another kind of orthopaedic surgery?
    \end{enumerate}
    \item How long did your post-operative physiotherapy last?
    \item Were you prescribed knee extensions as an exercise to do at home?
    \item In your opinion, did you encounter any trouble performing knee extensions? \textbf{YES/NO}
\end{enumerate}

\textbf{DEVICE LITERACY}
\begin{enumerate}
    \setcounter{enumi}{8}
    \item What do you use your mobile device for?
    \item How comfortable are you using the camera? 
    \\\textbf{Very comfortable\qquad Somewhat comfortable\qquad Comfortable\qquad \\Not comfortable}
    \item Do you know what a mobile phone tripod is? (selfie stick)
    \item How comfortable are you using the tripod?
    \\\textbf{Very comfortable\qquad Somewhat comfortable\qquad Comfortable\qquad \\Not comfortable} 
\end{enumerate}
\textbf{PRIVACY} \\
The next few questions should be asked by the investigator conducting the study.
\begin{enumerate}
    \item Participant identification information will be stored on a database. 
    \item Information extracted from the recording used in the application will also be stored on a database.
    \item The database used in the application adheres to data privacy standards and regulations. %TODO add firestore privacy ref
    \item All participant data will be deleted within (2 weeks?) after storage. 
    \item Information access is restricted to any external parties (except the application developers for the duration mentioned above).
    \item All participant data will be deleted within (2 weeks?) after storage. 
\end{enumerate}
