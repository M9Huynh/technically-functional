\section{Creating an account} 

After participant verification, the application will be downloaded on the their device. The participant 
will be asked to launch the application and will proceed through each stage below. \\

\noindent \textbf{Please click on 'create account' to be redirected to the account creation functionality. An invite code/PT license 
number should be provided to the participant. The duration to accomplish this task should be recorded.}\\ 
\textit{If the participant selects the \textbf{NO} option for any \textbf{YES/NO} questions, please inquire further.} 

\subsection{UI}
\begin{enumerate}
    \item Are the different elements on the screen logically positioned? \textbf{YES/NO} 
    \item Is the text font size sufficient for reading?
    \item Can you clearly distinguish between the different colours on the screen?
    \item Are the buttons appropriately sized?
\end{enumerate}

\subsection{Functionality}
\begin{enumerate}
    \setcounter{enumi}{4}
    \item Rate the difficulty level for creating an account: low, medium, high
    \\\textbf{Very easy \qquad Easy \qquad Somewhat difficult \qquad Difficult}
    \item Do you have any comments/improvements for account creation?
\end{enumerate}
\textbf{Once the account has been created, the next step will be navigation to the home screen. 
Initially, the home screen will be empty. It will be populated once an exercise has been recorded.}
